# Contributors

Repository owner and initial maintainer: [Erchard](https://github.com/Erchard).
Commit history records code and documentation authorship; attribution is retained
under the [licensing policy](docs/licensing.md).

Accepted scientific contributions are recorded with evidence in the
[reproduction ledger](docs/reproduction-ledger.md). Categories include
reproduction, negative result, falsification, prior art, implementation and audit.
An AI tool name is not proof of independence; record the accountable submitting
account and review evidence. No independent-reproducer status is awarded by
creating this file.

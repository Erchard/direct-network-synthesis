# DAS-V0 Protocol: Exact Spectral Automaton Reconstruction

Status: locked protocol, no result inspected at the time of writing.

## Question

Can a finite-rank sequence behavior be reconstructed directly from complete
Hankel subblocks into a compact weighted automaton, without iterative parameter
optimization?

This is a mathematical support experiment for Direct Network Synthesis. It does
not test image classification, language modeling or the DNS05 RBF compiler. It
asks whether the broader `data -> compact internal state -> parameters` idea has
a clean exact case with an auditable theorem-shaped boundary.

## Related-Work Boundary

The experiment is based on established spectral learning and weighted-automata
theory. In particular, the finite-rank Hankel characterization and spectral
extraction formula are treated as prior work, not DNS novelty. Checked anchors:

- Borja Balle and Mehryar Mohri, "Learning Weighted Automata", CAI 2015.
- Borja Balle and Mehryar Mohri, "Spectral Learning of General Weighted
  Automata via Constrained Matrix Completion", NeurIPS 2012.
- Daniel Hsu, Sham Kakade and Tong Zhang, "A Spectral Algorithm for Learning
  Hidden Markov Models", JCSS 2012.

This protocol does not claim a completed literature review.

## Fixed Configuration

Config: `configs/das_v0.json`.

Finite-rank fixtures:

| Fixture | Alphabet | States | Seed |
|---|---:|---:|---:|
| `rank2_seed_97001` | `{a,b}` | 2 | 97001 |
| `rank3_seed_97002` | `{a,b}` | 3 | 97002 |
| `rank4_seed_97003` | `{a,b}` | 4 | 97003 |

The teacher automata are generated by `random_stable_automaton` with fixed
normal initial/final vectors and fixed scaled normal transition matrices.

Basis selection uses all words over `{a,b}` up to length 5. Held-out checking
uses all words up to length 9. The held-out set is not used to select basis,
rank, tolerance or fixture seeds.

Rank tolerance: `1e-9`.
Success error tolerance on held-out words: `1e-8`.

Negative fixture: `anbn_indicator`, the indicator of `a^n b^n` for `n > 0`.
Record finite Hankel ranks for windows 1 through 5. Its purpose is to show that
the finite-rank assumption is substantive. Do not reinterpret a finite window
fit as general recovery for this language.

## Metrics

For each finite-rank fixture record:

- selected Hankel rank;
- state budget of the reconstructed automaton;
- prefix count and suffix count;
- singular values and Hankel condition number;
- maximum absolute error on basis words;
- maximum absolute error on held-out words;
- synthesis time;
- inference time on the held-out word set.

For the negative fixture record:

- finite-window Hankel rank for each locked window;
- whether the rank keeps increasing across the locked windows.

## Decision Rule

Positive V0 signal:

1. every finite-rank fixture reconstructs to the expected state count;
2. every finite-rank fixture has held-out maximum absolute error below `1e-8`;
3. the negative fixture shows increasing finite-window rank.

Failure or mixed result:

- any reconstruction error above tolerance;
- selected rank below or above expected state count;
- basis selection failure under the locked window;
- negative fixture rank not increasing.

Any failure is recorded as evidence about the extraction setup, not hidden by
changing seeds, windows or tolerances after inspection.

# DNS 0.5 Fresh Confirmation Protocol v1

Status: locked before confirmation evaluation, 2026-09-06.

Question: does the frozen train-sample-free hybrid prototype candidate survive
outside the reused digits development boundary, and how does it compare with the
strong retained-landmark and oracle references under the same selection rules?

This is a small confirmation step, not a broad scaling claim. It does not test
large images, language modeling, one-pass learning, energy use or novelty.

1. Datasets are fixed before running outcomes:
   `sklearn_breast_cancer` and `synthetic_multiclass_v1`.
   `sklearn_breast_cancer` is loaded from scikit-learn. `synthetic_multiclass_v1`
   is generated by `sklearn.datasets.make_classification` with 1200 samples,
   40 features, 16 informative features, 8 redundant features, 6 classes,
   2 clusters per class, class separation 1.2, label noise 0.03 and generation
   seed 62026.
2. Use five stratified 60/20/20 splits per dataset with split seeds 1101, 1202,
   1303, 1404 and 1505. These seeds are not the digits development seeds.
3. Fit preprocessing, oracle bandwidth selection, representations and readouts
   on train data only. Select readout alpha/intercept using validation only.
   Score the test partition once per model/split, after validation selection.
4. Candidate models are locked: linear, fixed ReLU 256, uniform Nystrom 192,
   hybrid prototypes 192, spectral 192 and full RBF. No dipole, class-PCA,
   compiled, farthest, class-balanced or RFF variants are evaluated here.
5. Use the same RBF oracle selection grid as the development diagnostics:
   gamma multipliers [0.5, 1.0, 2.0] and alpha [0.001, 0.01, 0.1]. Reuse the
   selected train/validation gamma for all RBF-derived representations.
6. Use alpha [0.001, 0.01, 0.1, 1.0] and intercept [false, true] for every
   readout. Tie-break validation selection by higher validation accuracy, then
   smaller alpha, then no intercept.
7. `fixed_relu_256` uses enough deterministic seeded ReLU units to produce a
   256-dimensional feature matrix after appending the standardized input.
8. `prototype_class_hybrid_192` is frozen from DNS05-HYB: the 192-center budget
   uses class-PCA coverage centers plus two rival-axis boundary pairs per class;
   the shift fraction is 0.25 and quantiles are [0.1, 0.25, 0.5, 0.75, 0.9].
9. Record validation accuracy, test accuracy, RMSE, R2, train-kernel
   reconstruction error, rank, feature budget, retained train samples,
   prototype count, exact train-row prototype matches, model-state bytes,
   intermediate-array estimates, construction time, readout solve time and
   validation/test prediction time.
10. Report mean, sample standard deviation and paired differences separately per
    dataset. Do not pool datasets into one headline score.
11. Treat the result as confirmation only for this narrow candidate and these
    two fresh boundaries. If hybrid fails to stay close to Nystrom or RBF, record
    the failure and do not tune the formula against these test outcomes. Any
    revised formula needs a new independent confirmation boundary.

Decision rule: hybrid prototypes become a retained train-sample-free candidate
only if their test accuracy is consistently close to uniform Nystrom and clearly
above fixed ReLU on both datasets while keeping zero retained train samples and
zero exact train-row prototype matches. If the result is mixed or worse, the
synthetic-center branch remains a development clue rather than a confirmed
candidate.

# Start Here for Agents

DNS asks whether useful representations can be computed without iterative
parameter optimization. Success is open; negative evidence is welcome.

1. Read [AGENTS.md](../AGENTS.md) and its required documents. The
   [methodology](methodology.md) controls every experiment.
2. Read the latest [research log](research-log.md), inspect the working tree and
   distinguish implemented results from planned work.
3. Choose one [open issue](https://github.com/Erchard/direct-network-synthesis/issues)
   with a bounded output. The [task catalog](agent-task-catalog.md) lists drafts
   and label meanings; drafts are not claims that live issues exist.
4. Identify allowed and protected data before running anything. Previously
   inspected test partitions are not fresh evidence. Some README commands score
   test data. Do not run them as installation checks.
5. Work in a fork/branch and return a PR under [CONTRIBUTING.md](../CONTRIBUTING.md):
   source commit, commands, environment, seeds, data seen, artifacts, checks,
   failures and limitations. Leave protected tests untouched unless a locked
   confirmation protocol and authorized task explicitly require access.

Current direction: the hybrid-center scaling audit was mixed-to-negative.
Further formula tuning on inspected boundaries is paused. Bounded-memory maps
and genuinely composed blocks are proposed directions; category theory is a
supporting question, not an implemented compiler.

The portable contributor skill is
[`skills/direct-network-synthesis-contributor/SKILL.md`](../skills/direct-network-synthesis-contributor/SKILL.md).
It is not a social bot and grants no credentials or publication authority.
